# Perfil público da Dona no GitHub

[![Documentação em Markdown](https://img.shields.io/badge/documentação-Markdown-083fa1?logo=markdown&logoColor=white)](profile/README.md)

Este repositório mantém o perfil público da organização [dona-events](https://github.com/dona-events). A Dona reúne convites digitais, informações da celebração e presentes para quem organiza eventos e seus convidados.

**Produto:** [dona.events](https://dona.events) · **Instagram:** [@app.dona](https://www.instagram.com/app.dona/)

## Estrutura e publicação

| Arquivo | Público e finalidade |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Apresentação pública exibida na página da organização no GitHub. |
| `README.md` | Orientações de manutenção deste repositório. |

O GitHub exibe o conteúdo de `profile/README.md` da branch padrão como perfil da organização. Este repositório não contém código de aplicação, manifests de dependências, scripts de build, testes ou workflows de CI. Sua manutenção não exige instalação de dependências nem configuração de variáveis de ambiente.

## Como atualizar

1. Edite `profile/README.md` para atualizar a apresentação pública ou este README para ajustar as orientações de manutenção.
2. Use informações verificáveis e links oficiais. Mantenha detalhes internos, credenciais e documentação restrita fora deste perfil público; o perfil destinado a membros pertence ao repositório `.github-private`.
3. Confira os links e a renderização Markdown na prévia do GitHub.
4. Envie as alterações por pull request para revisão antes da integração na branch padrão.

Não adicione instruções de execução de outros projetos ou badges de versão, build e cobertura sem uma fonte correspondente neste repositório. A documentação técnica de cada aplicação deve permanecer em seu próprio repositório.
